# R1 Safe Defaults

The supported local/reference profile enables only public credentialless collection by default: the built-in CISA KEV scheduler path and CIRCL Vulnerability-Lookup. Credential-bearing external framework integrations remain disabled until explicitly configured server-side.

This is a usability default, not an assurance claim. Runtime results remain attributable source observations and do not imply health, completeness, local exposure, compromise, remediation or publication authority.
