# Visual Analytics Workspace

The canonical Visual Analytics recovery surface is targeted at `/workbench/analytics` and is read-only in this bounded slice.

It visualizes attributable DTMO data only. Initial views consume the canonical Command Center trend/distribution data and vulnerability analytics data already exposed through DTMO same-origin APIs. Empty or unavailable inputs remain visibly empty/unavailable; the workspace does not manufacture values to make charts appear populated.

Every graphical view must have a text/table equivalent and labels that do not rely on colour alone. The surface does not prove live connector connectivity or local asset exposure, and it grants no review, sharing, case or publication authority.

The existing governed UI-07 screenshot is not replaced by this functional recovery. Screenshot migration remains a separate governed lifecycle after exact-head functional acceptance.
