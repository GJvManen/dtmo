# RUN-20260828-388 — R5 collection observation age analytics

## Scope

One bounded R5 recovery slice after merged PR #386: expose the age of the latest persisted connector-run start per connector in canonical Visual Analytics.

## Repository evidence

- Command Center groups connector runs by `ConnectorRun.connector_id` and reads the latest persisted `ConnectorRun.started_at` timestamp.
- Observation age is calculated in hours relative to the Command Center snapshot generation time.
- Visual Analytics renders the values as an accessible chart and table.
- Canonical-store failure returns `collection_observation_age: []`; values are never synthesized.
- Existing RBAC, server-side credential boundaries, provenance and human review/share/publication authority are unchanged.

## Claim boundary

It does not prove live connectivity, local exposure, source reachability, connector health, operational freshness, current upstream availability, successful present-time collection, compromise, review completion, sharing approval, publication authority, staging operation, production-equivalent operation, penetration-test results or independent assurance.
