## Check

Fresh standards/security review used the W3C Trace Context Recommendation. The specification requires strict parsing of potentially malicious headers, identifies information-exposure and denial-of-service risks, and states trace context must not contain personally identifiable or otherwise sensitive information. The implementation follows that boundary by accepting only the fixed version-00 identifier format and never treating `tracestate`, raw request data, credentials or identities as trace attributes.
