# RUN-20260806-021 — RC5.1 SQLAlchemy model integration

## Objective
Integrate the canonical intelligence classifications and confidence model into SQLAlchemy persistence without yet claiming migration, repository, service, API or end-to-end completion.

## Implemented
- `IntelligenceItem.item_type` now uses `IntelligenceType` through a portable non-native SQLAlchemy enum.
- `IntelligenceItem.severity` now uses `IntelligenceSeverity`.
- Confidence persistence is split into score, level and auditable rationale.
- Confidence and education-relevance database check constraints enforce values from 0 through 100.
- Provenance records persist source reliability, primary-source status and content-integrity verification.
- Provenance duplicate evidence is constrained by item, source URL and content hash.
- `IntelligenceRevision` stores ordered immutable snapshot metadata and prevents duplicate revision numbers or content hashes per item.
- Bidirectional cascade relationships are defined for provenance and revisions.
- Metadata-level regression tests protect enum mappings, constraints and relationships.

## Explicitly not completed
- Alembic migration for the changed schema.
- Data migration from the previous `confidence` and string classification columns.
- Repository and service layer integration.
- Ingestion mapping and transactional revision creation.
- API and OpenAPI schema integration.
- End-to-end persistence tests against PostgreSQL.
- Documentation merge to `main`.
