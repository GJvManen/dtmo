# RUN-20260806-011 — Aggregate CI release gate

- **Started:** 2026-08-06 08:51 CEST
- **Workstream:** Phase 1 — CI and workflow integrity
- **Roadmap objective:** Ensure release-critical job outcomes are aggregated into one independently observable release decision, rather than relying on workflow-file presence or isolated job visibility.

## Plan

Implement a final `release-gate` job that always executes after all release-critical jobs, evaluates their actual GitHub job results, fails closed when required evidence is missing or unsuccessful, and publishes a machine-readable evidence artifact. Regression-protect this behavior in the workflow contract tests.

### Blocking gates

1. The aggregate gate depends on workflow contracts, tests, migrations, container validation and dependency review.
2. Required jobs must report `success`; dependency review may only be `success` or `skipped` when not applicable.
3. A failed, cancelled or absent required result must produce a `blocked` decision and a non-zero exit.
4. The decision, job results, run identity and commit SHA must be uploaded as an artifact.
5. Contract tests must detect removal or weakening of the aggregate gate.
