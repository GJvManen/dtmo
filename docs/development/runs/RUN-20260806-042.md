The deterministic cause was the service-container environment contract: the dotted setting did not disable the image entrypoint security installer. The workflow now uses the documented container entrypoint variable `DISABLE_SECURITY_PLUGIN=true`, preserving an isolated HTTP-only test service without introducing credentials or changing production configuration.

## Act
