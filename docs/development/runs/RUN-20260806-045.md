# RUN-20260806-045 — RC7.2 persistent connector state and failure isolation

- **Started:** 2026-08-06 17:28 CEST
- **Workstream:** Phase 4 — live connector reliability and provenance
- **Objective:** Persist connector run state and source-health history, isolate repeatedly failing connectors, and support human-reviewed quarantine recovery without automatic publication.

## Plan

Blocking gates:

- connector state and health history must survive process restarts in PostgreSQL;
- repeated failures must isolate only the affected connector for a bounded interval;
- successful recovery must reset the failure counter and close isolation;
- quarantined evidence must retain its raw-evidence hash and recovery history;
- quarantine release requires an identified human reviewer and review reference;
- released evidence returns only to candidate state and may never imply publication approval;
- schema migration must be reversible;
- exact-head GitHub Actions and retained evidence are mandatory.
