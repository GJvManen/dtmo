# RUN-20260827-379 — R1 safe public local/reference bootstrap

## Scope

First bounded implementation slice from `PHASE11_FUNCTIONAL_UX_RECOVERY_PLAN.md` R1.

The local/reference `.env.example` now enables the server-owned live connector scheduler and the credentialless CIRCL Vulnerability-Lookup connector. Because CISA KEV is the built-in scheduler baseline when live connectors are enabled, a fresh supported local/reference profile can obtain attributable public-source content without requiring an upstream secret.

OpenCVE remains disabled because the supported API path requires an organization token. MISP, AIL, Taranis AI, IntelOwl, Cortex, OpenCTI and TheHive remain disabled until their existing server-side prerequisites are satisfied.

## Boundaries

- no production or staging default is changed;
- no credential-bearing integration is auto-enabled;
- no browser receives an upstream credential;
- connector success remains request/runtime evidence only and does not prove upstream completeness, local exposure, compromise, remediation or production readiness;
- RBAC, provenance, fail-closed behavior and human review/share/publication authority are unchanged.

## Acceptance

Repository tests must lock the safe public defaults and the authoritative installation guide must describe exactly what a clean local/reference bootstrap enables. Fresh exact-head CI is required before merge.
