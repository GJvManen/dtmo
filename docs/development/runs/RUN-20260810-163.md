## Do

The failure logs were inspected rather than inferred. The observed shared root-cause set was:

1. semantic UI state regressions: analyst empty results lost `data-state=empty`; analyst/CISO/auditor permission denial paths used generic `error` instead of `forbidden`;
2. session announcement regression: critical principal status regions lost `aria-atomic=true`;
3. auditor evidence identity regression: rendered audit rows lost `data-event-id`, breaking independently addressable evidence rows;
4. keyboard focus regression: the analyst search input had no observable outline or box-shadow focus indicator;
5. responsive/reflow regression: the redesigned role surfaces overflowed the 360 px accepted viewport;
6. contrast-evidence regression: decorative background gradients/images made accepted contrast measurement fail closed.

Remediation:

- restored `empty` and `forbidden` semantic states;
- restored `aria-atomic=true` on critical principal live regions;
- restored `data-event-id` on rendered audit evidence rows;
- introduced `/ui/rc9-compat.css`, loaded by all four role workspaces, with explicit visible focus, min-width/reflow constraints, mobile grid collapse and solid measurable surfaces;
- removed decorative background images from measured role-workspace surfaces through the compatibility layer;
- added repository regression assertions for the restored state, announcement, evidence-identity, focus, reflow and contrast contracts.

No backend authorization rule, role permission, publication/share-approval rule, audit persistence rule or external-assurance claim was relaxed.
