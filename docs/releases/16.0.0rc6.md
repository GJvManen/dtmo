# DTMO 16.0.0rc6 — Professional frontend UX overhaul

## Release objective

16.0.0rc6 turns the functional rc5 frontend into a coherent professional operator experience suitable for external UX, accessibility and staging validation while preserving all existing governance and security claim boundaries.

## User-facing changes

- redesigned Threat Operations Console with persistent information architecture for Overview, Intelligence, Governance, Audit and Security;
- professional status/KPI presentation for API, environment, connector state and publication gate;
- improved analyst search with focused search interaction, structured result cards and explicit loading/empty/error states;
- redesigned review/share workflow that visually and operationally reinforces separation of duties;
- read-only audit evidence table with principal, decision, resource and hash visibility;
- isolated CISO token-revocation workspace for high-impact security actions;
- role-focused Analyst, Share Approval, Auditor and CISO pages updated to the same design language;
- responsive navigation and reflow for tablet/mobile widths;
- per-tab test-identity dialog for local/dev/staging validation;
- stronger visual hierarchy, spacing, typography, focus treatment and action semantics.

## Accessibility and UX controls

- semantic landmarks and heading hierarchy;
- skip navigation;
- visible `:focus-visible` treatment;
- native dialog and form controls;
- live status regions;
- keyboard-operable navigation/actions;
- responsive reflow;
- reduced-motion behavior;
- text alternatives accompanying state color.

Genuine VoiceOver/NVDA evidence remains external and is not closed by this release.

## Security and governance

No authorization decision was moved to the browser. Server-side RBAC remains authoritative. Review and share approval remain separate permissions and separate governed actions. Audit evidence remains read-only. Service accounts still cannot gain human publication authority. Local test identity data is scoped to browser-tab `sessionStorage`; no bearer token or secret is embedded into frontend source.
