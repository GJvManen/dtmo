# DTMO 16.0.0rc9

Status: `CI_VALIDATION_PENDING`

## Theme

Safe registered-source execution and curated intelligence source catalog.

## Added

- DNS-resolving, IP-pinned HTTPS execution path for enabled registered JSON sources;
- fail-closed rejection of non-global destinations and redirects;
- JSON media-type validation and 5 MiB response bound;
- NIST NVD CVE API 2.0 normalizer;
- GitHub Global Security Advisories normalizer;
- canonical DTMO JSON v1 adapter contract for governed custom feeds;
- human-admin source run endpoint with persistent execution audit event;
- connector health/failure isolation and operational alert integration;
- curated source catalog and idempotent bootstrap of supported feeds, disabled by default;
- expanded Admin Source Registry UI with catalog, bootstrap and run controls;
- documentation for official, vendor and education-sector source onboarding targets.

## Source catalog

The catalog covers CISA KEV, NVD, GitHub Global Security Advisories, NCSC-NL, CERT-EU, Microsoft MSRC, Cisco, Red Hat, Ubuntu, Debian, Apple, Chrome, Mozilla, Fortinet, Palo Alto, Broadcom/VMware and ENISA. Education-sector onboarding targets include School-CERT/Kennisnet and SURF/SURFcert materials/interfaces where distribution conditions permit automation.

Only CISA KEV, NVD, GitHub Global Security Advisories and the canonical DTMO JSON v1 contract are executable in this release. Other catalog entries remain explicit parser/research targets rather than falsely claimed live connectors.

## Governance

Execution produces candidate intelligence only. Existing review, separation-of-duties and human external-share approval controls remain unchanged. Catalog membership, registration and source execution are not publication approval.

## Acceptance

No PASS is claimed until every registered workflow succeeds on the final exact PR head. Real staging, external service contractual access, assistive-technology execution, penetration testing, external assurance and production go/no-go remain outside this release claim.
