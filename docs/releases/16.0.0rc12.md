## Source framework prerequisite

RC11 completed the current operational vendor onboarding set through the unified `SourceAdapterRegistry`. The authoritative source status is maintained in `docs/qa/SOURCE_CONNECTION_MATRIX.md`. Research-reference entries remain deliberately non-executable where appropriate.

## Security and governance boundaries

- server-side RBAC remains authoritative;
- source operations and dashboards do not grant review or publication authority;
- human review and separate external share approval remain distinct decisions;
- Grafana anonymous access remains disabled;
- Grafana intelligence reporting uses a dedicated least-privilege role and explicit reporting views rather than the DTMO application database identity;
- credential values are not stored in the source catalog or registry;
- provenance, privacy, auditability and fail-closed execution requirements remain in force;
- native accessible chart/table fallbacks remain available.

## User-facing architecture

The intended product entry point is `/` with `/ui/console` as an alias. Source catalog/operations, administration, intelligence investigation and graphical analytics are integrated in this shell. Legacy `/ui/*` routes may remain for compatibility but are not separate intended product shells.

Grafana browser integration is served through the managed same-origin `/grafana/` path.
