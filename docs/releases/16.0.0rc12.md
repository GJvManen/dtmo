## RC13.3 identity boundary

DTMO validates externally issued production bearer tokens. The RC13.3 managed principal/role registry is auditable provisioning/assignment state and does not mint, forge or silently rewrite active bearer-token claims. Production role changes require identity-provider reconciliation or token reissue.

Built-in security roles remain code-controlled. Service accounts remain restricted to the `service_account` role; browser administration cannot create arbitrary custom token roles or combine machine and human/admin authority.
