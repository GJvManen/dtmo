# Supported Versions

DTMO has not yet reached production general availability.

| Version / branch | Security support | Status |
|---|---:|---|
| `main` | Yes | Current integration baseline |
| Explicit active release-candidate branch | Yes, while active | Pre-production validation only |
| Older RC branches and historical commits | No | Evidence/history only |
| Production release | Not yet available | Phase 10 remains blocked |

Security fixes are normally applied to the current supported baseline first. Backports are not promised unless a supported release policy is explicitly introduced.

This file does not change production-readiness status. A version becomes production supported only after the applicable roadmap, staging, external assurance and go/no-go gates have objective evidence.
