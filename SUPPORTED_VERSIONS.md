# Supported Versions

DTMO has not yet reached production general availability.

| Version / branch | Security support | Status |
|---|---:|---|
| `main` | Yes | Current integration baseline |
| `16.0.0rc12` / active RC branch | Yes, while active | Current pre-production validation baseline |
| Older RC branches and historical commits | No | Evidence/history only |
| Production release | Not yet available | Phase 10 not yet approved |

Security fixes are applied to the current supported baseline first. Backports are not promised unless a supported release policy is explicitly introduced.

`16.0.0rc12` becomes a production-supported release only after Phase 8 external staging acceptance, Phase 9 external assurance and Phase 10 production go/no-go are complete.
